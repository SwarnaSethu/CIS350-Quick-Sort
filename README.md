# Quick Sort: From Hand Trace to Recursion Tree

An interactive board for CIS 350 Data Structures (Missouri Southern State University).
It is a single HTML file. It needs no installation.

## How to open it
- Open the board link: https://swarnasethu.github.io/CIS350-Quick-Sort/
- Or download `index.html` from this repository and open it in any web browser.

## How to use it
- Click **Next** and **Back**, or use the left and right arrow keys, to move through the board.
- Click a topic in the list on the left to jump to it.
- Slide 5 is an interactive recursion tree. **Next** and **Back** step through every call, down into the tree and back up as each call returns.
- Use a full-screen browser window for the best fit.

## What it covers
All slides use the example list [5, 1, 4, 2, 8, 3], with the last value as the pivot.

1. What one partition guarantees.
2. Tracing one partition by hand with low, high, pivot, i and j.
3. Finishing the hand trace on the two remaining ranges, and where the calls stop.
4. Turning the hand trace into pseudocode for Partition and QuickSort.
5. Following the recursive calls as a tree.
6. Writing the C# program one piece at a time: Main, QuickSort, Partition and Swap.
7. The whole program.
8. Worst case (a sorted list) and best case (balanced splits).
9. Choosing the pivot.
10. Comparing Quick Sort with Bubble Sort and Selection Sort.
11. Check Yourself questions.

## Notes
- The board uses the Lomuto partition scheme. A short note explains how it differs from the Hoare scheme.
- The student handout and practice sheet are on Blackboard.
